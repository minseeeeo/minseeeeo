# Hi, I'm Minseo 👋

[English](README.en.md)

사용자가 화면에서 실제로 느끼는 경험을 기준으로 문제를 정의하는 **프론트엔드 개발자**입니다.

React · TypeScript 기반 웹 프론트엔드를 주력으로, 초기 세팅부터 API 연동·배포까지 프론트엔드 전 과정을 경험했습니다.  
웹에 머무르지 않고 React Native와 SwiftUI로 모바일 앱을 개발했으며, 1인 개발한 iOS 앱을 **App Store에 출시**했습니다.

화면 하나를 만들 때도 **데이터가 어디서 오고, 실패하면 사용자에게 무엇이 보이는지**까지 함께 설계하려고 합니다.
